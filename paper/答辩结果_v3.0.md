# 图像篡改检测（v3.0）答辩结果速览

> 数据口径：纯真实 CASIA 验证集 2,866 张（真 1,658 / 拼接 466 / 复制移动 742），不含 TIGAS 与合成数据。

## 1. 一句话结论

四分支注意力融合网络（FBFN）升级到 DINOv2-L 大骨干后，实现了**真伪判别 + 篡改类型分类 + 像素级定位**三任务统一；在真实 CASIA 上类型 macro-F1 达 **0.849**、分割 mIoU 达 **0.584**，并通过阈值与温度校准把二分类准确率提升到 **89.95%**、F1 达 **88.47%**。

## 2. 最终指标（部署配置）

| 任务 | 检查点 | 指标 | 配置 |
|---|---|---|---|
| 真伪二分类 | ep30_raw | 准确率 **89.95%**，F1 **88.47%**，AUC 0.9587 | 阈值 0.18，温度 1.88 |
| 篡改类型（3 类） | ep20_ema | 准确率 **86.36%**，macro-F1 **0.8492** | 默认 argmax |
| 像素级定位 | ep30_raw | mIoU **0.5836**，分割 F1 **0.7371** | 阈值 0.5 |

参考：旧小骨干（256×256，Swin-T/ResNet-34）类型 F1 0.818、mIoU 0.490、AUC 0.977 —— 新版本在类型与定位上全面超越，二分类 AUC 略低。

## 3. 训练过程（真实 CASIA）

| 检查点 | AUC | 类型 F1 | mIoU |
|---|---|---|---|
| ep5 | 0.9230 | 0.7179 | 0.3323 |
| ep10 | 0.9555 | 0.8019 | 0.4830 |
| ep14 (EMA) | 0.9672 | 0.8251 | 0.5437 |
| ep20 (EMA) | 0.9634 | 0.8492 | 0.5614 |
| ep30 | 0.9587 | 0.8394 | **0.5836** |
| ep40 (EMA) | 0.9473 | 0.8412 | 0.5807 |

## 4. 三个值得讲的点

1. **类别加权救不了复制移动，联合训练可以**：类型 F1 从 0.718（5 轮）升到 0.849，分割 mIoU 从 0.332 升到 0.584，说明类型判别与定位任务互相促进。
2. **默认 0.5 阈值不是最优**：搜索后阈值 0.18 使准确率 +1.8 个点、二分类 F1 +3.3 个点；温度缩放（T≈1.88）把期望校准误差 ECE 从 0.081 降到 0.059，置信度更可信。
3. **集成性价比低**：ep20_ema + ep30 的 logits 融合只把 AUC 提高约 0.001、类型 F1 提高约 0.3 个点，推理翻倍，最终不采用。

## 5. 局限与后续

- 复制移动召回约 **74.8%**（常被判为真实），是最弱项；拼接召回约 86%
- 最优阈值在 CASIA 上拟合，换数据域需重新校准
- 验证集仅覆盖 CASIA，跨数据集泛化仍待评估
- 后续方向：更难的合成复制移动数据 + 对比学习微调

## 6. 复现

- 代码：https://github.com/changest/Image-Tampering-Detection-3.0 （分支 `v3.0`）
- 权重：`ep30_raw.pth`（二分类+分割）、`ep20_ema.pth`（类型），可向团队索取
- 评测：`python -m fbfn.eval_real --model large --img_size 448 --ckpt <权重>`
- 校准：`python -m fbfn.calibrate --ckpt <权重> --model large --img_size 448`
