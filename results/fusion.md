# 二分类分数融合实验（max-pool + 集成）

## 目的

检验两种低成本提升二分类 AUC 的方式：
1. 多检查点 logit 集成；
2. 把 `final_map` 的 max-pool 响应与二分类 logit 融合（小面积篡改在全局平均中会被稀释）。

## 单模型（真实 CASIA 2,866 张）

| 模型 | 二分类 AUC | max-pool AUC |
|---|---|---|
| ep20_ema | 0.9634 | 0.9284 |
| ep30_raw | 0.9587 | 0.8893 |
| last_ema | 0.9503 | 0.9057 |

## 集成

| 组合 | 全验证集 AUC |
|---|---|
| ep20 + ep30 + last_ema | 0.9612 |
| ep20 + ep30 | 0.9639 |
| ep20_ema 单模型 | 0.9634 |

结论：**集成为负收益或无收益**，last_ema 会拖累整体。

## max-pool 融合（ep20_ema）

标准化后用 `0.75·z(bin_logit) + 0.25·z(max_logit)`：
- 全验证集：AUC **0.9676**（单模型 0.9634，+0.0042）
- 留出法（偶数索引拟合 α 与常数，奇数索引报告）：**0.9667 vs 0.9605，+0.0062**
- 二分类准确率未提升（约 89%），主要收益在排序/AUC

## 结论

- 融合仅改变排序，不改变最优阈值下的准确率；适合离线复核排序，不适合直接替换 Demo 的概率输出。
- 若要继续提升，需要冻结骨干单独微调二分类头，而不是继续做分数组合。

复现：`python -m fbfn.eval_scores` / `python -m fbfn.eval_real --fusion`
