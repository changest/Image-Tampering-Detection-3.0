# 分割 mIoU 提升实验

## 阈值扫描（ep30_raw，单次前向）

| 阈值 | mIoU |
|---|---|
| 0.25 | 0.5860 |
| 0.50 | 0.5836 |
| 0.85 | 0.5660 |

最优 0.25 仅 +0.0024，说明瓶颈不在判定阈值。

## 水平翻转 TTA + 阈值

对输入与 ELA 做水平翻转，前向后翻回平均，再扫描阈值：

| 阈值 | mIoU |
|---|---|
| 0.30 | 0.6009 |
| **0.40** | **0.6029** |
| 0.50 | 0.5935 |

**TTA + th=0.40：mIoU 0.6029（相比原始 0.5836，+0.0193）**。

## 取舍

- 分割前向 ×2；适合离线复核或高精度模式。
- 在线实时路径仍建议单次前向 + 阈值 0.25（0.5860）。

复现：`python -m fbfn.eval_seg_threshold --ckpt fbfn/runs_type/ep30_raw.pth --tta`
