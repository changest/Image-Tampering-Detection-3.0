# v3.0 最终结果

数据口径：纯真实 CASIA 验证集 2,866 张（真 1,658 / 拼接 466 / 复制移动 742）。

## 最优配置

| 任务 | 权重 | 指标 |
|---|---|---|
| 真伪二分类 | `ep30_raw.pth` | AUC 0.9587；阈值 0.18 时准确率 89.95%、F1 88.47% |
| 篡改类型（3 类） | `ep20_ema.pth` | 准确率 86.36%、macro-F1 0.8492 |
| 像素级定位 | `ep30_raw.pth` | mIoU 0.5836、分割 F1 0.7371 |

## 已尝试但未采用的改进

- 续训到 40 轮：30 轮后分类指标过拟合下降
- 复制移动类别加权：效果有限
- 困难 copy-move 微调（ep21–ep25）：召回 74.8%→79.6%，但精确率与整体 F1/mIoU 下降，判定边界平移而非判别力提升
- 双模型 logits 集成：AUC +0.001、F1 +0.3 点，推理翻倍，不划算
