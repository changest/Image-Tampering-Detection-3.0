# 借鉴 Jev-Mem 的案例记忆级联（MVP 实验）

## 设计

- 案例记忆：CASIA 训练集 11,469 条，SQLite 存 27 维廉价特征（ELA 统计 + 熵图统计 + 颜色矩）
- 系统一（S1）：用这些特征训练逻辑回归（无 CNN），推理成本约 3ms
- 级联：S1 置信度不足时升级全模型（last_ema，约 30ms）
- 记忆校准：检索 K=10 个相似案例，按相似度加权邻居标签，把 S1 概率向邻居均值收缩（λ=0.3）
- 分歧门控：邻居标签分歧大时强制升级

## 结果（CASIA 验证集 2,866 张）

| 方案 | rho | AUC | 平均延迟 |
|---|---|---|---|
| 全模型 | 1.00 | 0.9503 | 30 ms |
| 纯 S1（无记忆） | 0.00 | 0.6746 | 3 ms |
| S1 + 记忆校准 | 0.00 | 0.6938 | 3 ms |
| 普通阈值级联 | 0.59 | 0.8959 | 19.0 ms |
| 记忆校准级联 | 0.57 | 0.8908 | 18.5 ms |
| 记忆 + 分歧门控 | 0.34 | 0.8152 | 12.2 ms |
| 普通阈值级联（低升级） | 0.32 | 0.8240 | 11.7 ms |
| 普通阈值级联 | 0.79 | 0.9258 | 24.2 ms |
| 记忆校准级联 | 0.75 | 0.9187 | 23.2 ms |

## 结论

- 记忆校准把独立廉价分数的 AUC 从 0.6746 提升到 0.6938（+1.9 点），验证了"相似案例可用"。
- **但在相同升级比例下，记忆级联略低于普通阈值级联**（19ms: 0.8908 vs 0.8959；24ms: 0.9187 vs 0.9258），收益被额外误升级抵消。
- 级联本身收益显著：19ms 达到 0.8959、24ms 达到 0.9258（相对 30ms 全模型）。
- 结论：**不将案例记忆作为主线**；保留 `memory.py` 组件。若继续 Jev 方向，优先尝试"查询路由"（按图像类型选择分支）而非记忆校准。

## 复现

```
python -m fbfn.eval_memory_cascade --ckpt fbfn/runs_type/last_ema.pth --img_size 448 --k 10 --lam 0.3
```
首次运行会构建 `data/memory/casia_cases.sqlite`（约 12 分钟）。
